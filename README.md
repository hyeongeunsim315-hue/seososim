# AI 인테리어 추천 서비스

사용자가 원하는 분위기, 색상, 공간의 특이사항을 입력하면 벽지부터 바닥재, 가구와 가구 색상까지 추천하고, 결과를 2D 또는 3D로 확인할 수 있는 AI 인테리어 서비스입니다.

## 1. 프로젝트 개요

인테리어를 계획할 때 사용자는 원하는 분위기를 구체적인 제품과 색상으로 연결하기 어렵습니다. 또한 벽지, 바닥재, 가구를 각각 선택한 뒤 전체적인 조화를 미리 확인하기도 어렵습니다.

본 프로젝트는 사용자가 입력한 조건을 AI가 분석하여 공간 전체의 인테리어 구성을 추천하고, 추천 결과를 시각적으로 보여주는 것을 목표로 합니다.

### 프로젝트 기간

- 시작일: 2026년 8월 24일
- 발표일: 2026년 9월 9일

## 2. 문제 정의

- 원하는 인테리어 분위기를 구체적인 색상과 제품으로 정하기 어렵습니다.
- 벽지, 바닥재, 가구를 따로 선택하면 전체적인 조화를 예상하기 어렵습니다.
- 실제 시공 전에 완성된 공간의 모습을 확인하기 어렵습니다.
- 공간 크기와 특이사항을 고려한 가구 선택이 어렵습니다.

## 3. 주요 기능

### 3.1 사용자 조건 입력

사용자는 다음 조건을 입력하거나 선택할 수 있습니다.

- 공간 종류: 거실, 침실, 공부방 등
- 선호 분위기: 모던, 내추럴, 미니멀, 빈티지 등
- 선호 색상
- 피하고 싶은 색상
- 공간 크기
- 예산 범위
- 특이사항: 반려동물, 어린아이, 수납 부족, 채광 부족 등

### 3.2 AI 인테리어 추천

입력된 조건을 분석하여 다음 항목을 추천합니다.

- 벽지 색상 및 스타일
- 장판 또는 바닥재 색상과 재질
- 주요 가구 종류
- 가구 배치
- 가구 색상과 소재
- 조명 및 포인트 색상
- 추천 이유와 주의사항

### 3.3 결과 시각화

- 추천 색상과 소재를 한 화면에서 확인
- 가구 배치를 2D 화면으로 확인
- 추천 결과를 3D 공간으로 확인
- 추천 전후 비교
- 조건을 수정하여 다시 추천받기

## 4. 유즈케이스 시나리오

사용자가 다음과 같이 조건을 입력합니다.

> 채광이 부족한 작은 침실을 따뜻하고 깔끔하게 꾸미고 싶어요. 베이지색과 우드 색상을 좋아하고 수납공간이 많이 필요해요.

AI는 입력 내용을 분석하여 다음과 같이 추천합니다.

- 벽지: 밝은 아이보리 벽지
- 바닥재: 연한 오크색 장판
- 침대: 수납형 낮은 침대
- 가구: 밝은 우드 소재의 옷장과 협탁
- 조명: 따뜻한 색상의 간접조명
- 포인트 색상: 베이지와 연한 녹색

사용자는 추천 이유를 확인하고, 완성된 공간을 2D 또는 3D 화면으로 살펴볼 수 있습니다.

## 5. 서비스 동작 과정

1. 사용자가 공간과 인테리어 조건을 입력합니다.
2. AI가 사용자의 입력 내용을 분석합니다.
3. 벽지, 바닥재, 가구와 가구 색상을 추천합니다.
4. 각 항목을 추천한 이유를 제공합니다.
5. 추천 결과를 2D 또는 3D 화면으로 보여줍니다.
6. 사용자가 조건을 수정하여 다시 추천받을 수 있습니다.

## 6. MVP 기능

프로젝트 기간 내 완성을 우선하여 다음 기능을 MVP로 개발합니다.

- 공간 종류 선택
- 분위기와 선호 색상 선택
- 공간 특이사항 입력
- 벽지, 바닥재, 가구 및 가구 색상 추천
- 추천 이유와 색상 팔레트 제공
- 대표 공간 1종에 대한 2D 결과 화면 구현
- 추천 결과 저장 및 다시 보기

3D 시각화와 실제 가구 상품 연동은 MVP 완성 후 구현할 확장 기능으로 구분합니다.

| 구분 | 적용 기술 또는 후보 |
|---|---|
| 사용자 화면 | Python, PySide6 또는 웹 프레임워크 |
