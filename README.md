## Hi there 👋
AI 인테리어 추천 서비스

사용자가 원하는 분위기, 색상, 공간의 특이사항을 입력하면 벽지부터 바닥재, 가구와 가구 색상까지 조화롭게 추천하고 2D 또는 3D로 확인할 수 있는 AI 인테리어 서비스입니다.

1. 프로젝트 개요

인테리어를 계획할 때 사용자는 원하는 분위기를 설명하기 어렵고, 벽지·바닥재·가구를 각각 선택한 뒤 전체적인 조화를 미리 확인하기도 어렵습니다. 본 프로젝트는 간단한 조건 입력만으로 공간 전체의 인테리어 구성을 추천하고 시각화하여 사용자의 선택을 돕는 것을 목표로 합니다.

프로젝트 기간

시작: 2026년 8월 24일

최종 발표: 2026년 9월 9일

2. 문제 정의

사용자가 원하는 인테리어 분위기를 구체적인 제품과 색상으로 연결하기 어렵습니다.

벽지, 바닥재, 가구를 따로 고르면 전체적인 색상 조화를 예상하기 어렵습니다.

실제 시공 전에 완성된 공간의 모습을 확인하기 어렵습니다.

전문 인테리어 지식이 없는 사용자는 공간의 크기와 특이사항을 고려해 가구를 선택하기 어렵습니다.

3. 주요 기능

3.1 사용자 조건 입력

사용자는 다음 조건을 직접 입력하거나 선택할 수 있습니다.

공간 종류: 거실, 침실, 공부방 등

선호 분위기: 모던, 내추럴, 미니멀, 빈티지 등

선호 색상과 피하고 싶은 색상

공간 크기

특이사항: 반려동물, 어린아이, 수납 부족, 채광 부족 등

예산 범위

3.2 AI 인테리어 추천

입력된 조건을 분석하여 다음 항목을 하나의 인테리어 조합으로 추천합니다.

벽지 색상 및 스타일

장판 또는 바닥재 색상과 재질

주요 가구 종류

가구 배치

가구 색상과 소재

조명 및 포인트 색상

추천 이유와 주의사항

3.3 결과 시각화

2D: 추천 색상, 소재, 가구와 배치를 한 화면에서 확인

3D: 추천 결과를 가상 공간에 적용하여 여러 방향에서 확인

추천 전·후 비교

4. 유즈케이스 시나리오

사용자는 "채광이 부족한 작은 침실을 따뜻하고 깔끔하게 꾸미고 싶다"고 입력하고 베이지색을 선택합니다. AI는 밝은 아이보리 벽지, 연한 오크색 바닥, 낮은 침대와 밝은 우드 가구를 추천합니다. 사용자는 추천 이유와 색상 조합을 확인하고 2D 또는 3D 화면에서 완성된 공간을 미리 살펴봅니다.

5. 서비스 흐름

사용자가 공간과 인테리어 조건을 입력합니다.

입력 내용을 AI가 분석합니다.

벽지, 바닥재, 가구, 가구 색상을 추천합니다.

추천 결과와 선정 이유를 제공합니다.

결과를 2D 또는 3D 화면으로 보여줍니다.

사용자가 조건을 수정하여 새로운 추천을 받을 수 있습니다.

6. MVP 범위

프로젝트 기간 내 완성을 우선하여 다음 기능을 MVP로 개발합니다.

공간 종류, 분위기, 색상, 특이사항 입력

입력 조건에 맞는 인테리어 스타일 분석

벽지, 바닥재, 가구 및 가구 색상 추천

추천 이유와 색상 팔레트 제공

대표 공간 1종에 대한 2D 결과 화면 제공

추천 결과 저장 및 다시 보기

3D 시각화와 실제 가구 상품 연동은 MVP 완성 후 개발하는 확장 기능으로 구분합니다.

12. 테스트 계획

동일한 조건 입력 시 추천 형식이 일관적인지 확인

서로 어울리지 않는 색상 조합이 추천되지 않는지 확인

공간 특이사항이 추천 결과에 반영되는지 확인

필수 입력값이 없을 때 안내 메시지가 표시되는지 확인

추천 결과가 2D 화면에 정상적으로 나타나는지 확인
